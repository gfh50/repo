## 3. Развёртывание стенда (пошагово)

### Шаг 1: Создание виртуальных сетей

```bash
# Создать internal-сети в VirtualBox
VBoxManage hostonlyif create
VBoxManage hostonlyif ipconfig vboxnet0 --ip 192.168.56.1 --netmask 255.255.255.0

# Через GUI: File → Tools → Network Manager → Create
# Создать: vboxnet-cod (10.0.1.1/24), vboxnet-main (10.0.2.1/24)
```

### Шаг 2: Создание шаблонной ВМ (Debian 12)

```bash
# Скачать Debian 12 netinst ISO
wget https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.x.x-amd64-netinst.iso

# Создать ВМ через VBoxManage
VBoxManage createvm --name "debian12-template" --ostype Debian_64 --register
VBoxManage modifyvm "debian12-template" --memory 1024 --cpus 1 \
  --nic1 intnet --intnet1 "vboxnet-cod" \
  --boot1 dvd --boot2 disk --boot3 none --boot4 none
VBoxManage createmedium disk --filename ~/VMs/debian12-template.vdi --size 10240
VBoxManage storagectl "debian12-template" --name "SATA" --add sata
VBoxManage storageattach "debian12-template" --storagectl "SATA" \
  --port 0 --device 0 --type hdd --medium ~/VMs/debian12-template.vdi
VBoxManage storageattach "debian12-template" --storagectl "SATA" \
  --port 1 --device 0 --type dvddrive --medium ~/ISOs/debian-12-netinst.iso

# Установить Debian 12: SSH server, standard system utilities
# Логин: root / toor (как в КЗ)
```

### Шаг 3: Клонирование ВМ из шаблона

```bash
for vm in COD-RTR MAIN-RTR COD-WEB COD-DOCKER MAIN-STORAGE1 MAIN-STORAGE2; do
  VBoxManage clonevm "debian12-template" --name "$vm" --register --mode machine
done

# MAIN-DC1 — отдельно (Astra Linux или Rocky 9 для FreeIPA)
# PC1 — Astra Linux
# REMOTE-WORKER — Astra Linux
# KALI-ATTACKER — Kali Linux ISO
```

### Шаг 4: Настройка DNS и репозитория (эмуляция КЗ)

На хост-машине поднять DNS и репозиторий:

```bash
# /etc/hosts на ВСЕХ ВМ (добавить):

10.0.2.30  main-storage1.atomskills.cyber

# использовать стандартные зеркала Debian с записью в /etc/hosts
```

### Шаг 5: Snapshot «clean»

```bash
# После базовой установки — snapshot на каждой ВМ
```

## Лаборатория B1: Сетевая связность

**Цель:** отработать блок B1 (9.9 баллов) — L3, SSH, VPN, OSPF, PAT, HTTPS.
**Время:** 8 часов (2 тренировочных дня по 4 часа)

### Задание B1.1: L3-интерфейсы и SSH-hardening

**На каждой ВМ (COD-RTR, MAIN-RTR, COD-WEB):**

```bash
# 1. Настройка интерфейса (пример для COD-RTR)
cat > /etc/network/interfaces.d/eth0 << 'EOF'
auto eth0
iface eth0 inet static
    address 10.0.1.1
    netmask 255.255.255.0
EOF
systemctl restart networking

# 2. Создание пользователя sshuser
useradd -m -s /bin/bash sshuser
echo 'sshuser:P@ssw0rd' | chpasswd

# 3. SSH hardening
cat >> /etc/ssh/sshd_config << 'EOF'
PermitRootLogin no
AllowUsers sshuser
PasswordAuthentication yes
PubkeyAuthentication yes
EOF
systemctl restart sshd

# 4. Fail2ban
apt install -y fail2ban
cat > /etc/fail2ban/jail.local << 'EOF'
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/auth.log
maxretry = 2
bantime = 60
findtime = 600
EOF
systemctl enable --now fail2ban

# 5. auditd — логирование SSH
apt install -y auditd
auditctl -w /var/log/auth.log -p wa -k ssh_logins
auditctl -w /etc/ssh/sshd_config -p wa -k sshd_config
```

**Проверка:**
```bash
# С Kali: 3 неудачных входа → бан на 1 минуту
ssh root@10.0.1.1          # Permission denied
ssh baduser@10.0.1.1       # fail 1
ssh baduser@10.0.1.1       # fail 2 → banned
ssh sshuser@10.0.1.1       # Connection refused (banned)

# Через 60 сек:
ssh sshuser@10.0.1.1       # OK

# auditd:
ausearch -k ssh_logins | tail -5
```

### Задание B1.2: VPN между COD-RTR и MAIN-RTR

```bash
# === COD-RTR: WireGuard (резервный VPN) ===
apt install -y wireguard
wg genkey | tee /etc/wireguard/private.key | wg pubkey > /etc/wireguard/public.key

cat > /etc/wireguard/wg0.conf << 'EOF'
[Interface]
Address = 10.255.0.1/30
ListenPort = 51820
PrivateKey = <COD_PRIVATE_KEY>

[Peer]
PublicKey = <MAIN_PUBLIC_KEY>
AllowedIPs = 10.0.2.0/24, 10.255.0.0/30
Endpoint = <MAIN_WAN_IP>:51820
PersistentKeepalive = 25
EOF

# === MAIN-RTR: аналогично, Address = 10.255.0.2/30 ===
systemctl enable --now wg-quick@wg0

# Основной VPN — OpenVPN или IPsec (strongswan)
apt install -y openvpn easy-rsa
# ... генерация сертификатов, настройка туннеля ...

# Скрипт автопереключения при блокировке основного VPN:
cat > /usr/local/bin/vpn-failover.sh << 'SCRIPT'
#!/bin/bash
while true; do
  if ! ping -c 3 -W 2 10.0.2.1 > /dev/null 2>&1; then
    logger "Primary VPN down, activating WireGuard backup"
    wg-quick up wg0 2>/dev/null
  fi
  sleep 30
done
SCRIPT
chmod +x /usr/local/bin/vpn-failover.sh
```

### Задание B1.3: OSPF

```bash
# На COD-RTR и MAIN-RTR
apt install -y frr frr-pythontools

# /etc/frr/daemons → ospfd=yes
# /etc/frr/frr.conf (COD-RTR):
cat > /etc/frr/frr.conf << 'EOF'
frr version 8.x
frr defaults traditional
hostname cod-rtr
log file /var/log/frr/frr.log

interface tun0
 ip ospf area 0
 ip ospf authentication message-digest
 ip ospf message-digest-key 1 md5 OspfKey2026

router ospf
 ospf router-id 10.0.1.1
 network 10.0.1.0/24 area 0
 network 10.255.0.0/30 area 0

line vty
EOF

systemctl enable --now frr

# Мониторинг изменений маршрутов
cat > /usr/local/bin/ospf-monitor.sh << 'SCRIPT'
#!/bin/bash
LOG=/var/log/router_change.log
PREV=$(vtysh -c "show ip ospf route" 2>/dev/null)
while true; do
  CURR=$(vtysh -c "show ip ospf route" 2>/dev/null)
  if [ "$PREV" != "$CURR" ]; then
    echo "$(date '+%Y-%m-%d %H:%M:%S') Route change detected" >> "$LOG"
  echo "ALERT: OSPF routes changed at $(date)" | wall
    PREV="$CURR"
  fi
  sleep 10
done
SCRIPT
chmod +x /usr/local/bin/ospf-monitor.sh
```

### Задание B1.4: PAT и rate limit (nftables)

```bash
# На COD-RTR
apt install -y nftables

cat > /etc/nftables.conf << 'EOF'
#!/usr/sbin/nft -f
flush ruleset

table ip nat {
  chain postrouting {
    type nat hook postrouting priority srcnat; policy accept;
    oifname "eth1" masquerade
  }
}

table ip filter {
  chain input {
    type filter hook input priority filter; policy accept;
    iifname "eth1" ct state new limit rate over 100/second drop
  }
}
EOF

systemctl enable --now nftables
```

### Задание B1.5: HTTPS для COD-WEB + OpenVPN для REMOTE-WORKER
